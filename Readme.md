## Лабораторная работа №2

**Цель:** изучение основ HTML и CSS.

**Тема сайта:** «Лад» — гитарные аккорды и ритм для начинающих.

Сайт находится в папке `lab2`. Используются только HTML и CSS, без JavaScript,
Bootstrap, библиотек и фреймворков. Схемы аккордов — собственные SVG-изображения
без скриптов. Все ресурсы локальные, подключаемых шрифтов нет.

### Страницы

1. [Главная](lab2/index.html) — введение, навигация и стандартный строй гитары.
2. [Аккорды](lab2/chords.html) — шесть схем открытых аккордов и сравнительная таблица.
3. [Ритм](lab2/rhythm.html) — два рисунка боя в размере 4/4.
4. [Практика](lab2/practice.html) — упражнения и ответы на вопросы.

### Выполнение требований

| Требование | Реализация |
| --- | --- |
| От 3 до 5 страниц | Четыре HTML-страницы |
| Блочные элементы | `header`, `nav`, `main`, `section`, `article`, `div`, `p`, `footer` |
| Строчные элементы | `a`, `span`, `strong`, `em`, `code` |
| Ссылки | Навигация между страницами и ссылки на учебные материалы |
| Картинки | Шесть локальных SVG-схем в `lab2/images`, элементы `img` с описательными `alt` |
| Таблица | Состав и аппликатуры аккордов на странице `chords.html`; `caption`, `thead`, `tbody`, `th`, `td` |
| Отдельный CSS | `lab2/styles.css`, подключён через `link` на каждой странице |
| Не менее трёх видов селекторов | По тегу (`body`), классу (`.hero`), ID (`#chord-table`), атрибуту (`a[aria-current="page"]`); также псевдоклассы |
| Цвет | CSS-переменные, цвет фона, текста, ссылок и заголовка таблицы |
| Выравнивание в таблице | Название и ноты слева; количество струн справа; тип и аппликатура по центру |

Верстка адаптируется к небольшим экранам через медиазапросы. Широкая таблица
прокручивается внутри своего контейнера. Навигация отмечает текущую страницу;
предусмотрены видимый фокус и ссылка перехода к основному содержимому.
Ответы на вопросы раскрываются элементами `details` и `summary`.

### Запуск

Открыть `lab2/index.html` в браузере. Установка зависимостей и сборка не нужны.
Сайт работает с диска и без интернета. Интернет нужен только для внешних ссылок.

### Учебные материалы и примеры

- [JustinGuitar: Beginner 2 — Getting Minor](https://www.justinguitar.com/modules/beginner-2-getting-minor) — пример структуры учебного раздела: отдельные темы об аккордах и практика. Верстка, стили, тексты и схемы реализованы самостоятельно.
- [musictheory.net: Introduction to Chords](https://www.musictheory.net/lessons/40) — дополнительный материал о трезвучиях.

В схемах используется международное обозначение нот: B — си.
Аппликатуры читаются от шестой струны к первой: x — не играть, 0 — открытая струна.
Цифры в кружках — номера пальцев: от указательного (1) до мизинца (4).
Схемы предназначены для стандартного строя E–A–D–G–B–E.

Работа выполняется в отдельной ветке `lab2`; слияние с `main` — через pull request.
